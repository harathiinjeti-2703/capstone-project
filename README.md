# Capstone Project
This project analyzes a banking loan portfolio, including loan performance, repayments, transactions, and customer complaints. It uses Excel, SQL, Python, and Power BI to clean and analyze the data and present results in dashboards.


## Tools used
- Excel
- SQL
- Python
- Power BI


## Project files
- `capstone.project.xl.xlsx` — Excel workbook
- `capstone.sql` — SQL queries
- `fine_edge.py` — Python code
- `project_data.pbix` — Power BI report
  

## Workflow
1. Collected the datasets in Excel, cleaned the data, and created pivot tables and KPIs.
2. Loaded the data into SQL, created database tables, and wrote queries to answer the project questions.
3. Used Python to create visualizations, check the cleaned data, and prepare datasets for Power BI.
4. Loaded the datasets into Power BI, created relationships and DAX measures, and built dashboards.


## Key findings
- The paid-to-due repayment amount ratio was 96.24%.
- Transactions had an overall failure rate of 3.77% across 60,000 records.
- 50% of the 1,320 complaints with known SLA outcomes breached their service targets.
- Data quality checks found duplicate loan IDs and missing disbursal dates, so loan risk results should be interpreted carefully.


## Results
- Analyzed 4,352 loan records.
- Repayment paid-to-due ratio: 96.24%.
- Transaction failure rate: 3.77% across 60,000 transactions.
- Complaint SLA breach rate: 50% of 1,320 complaints with known outcomes.
